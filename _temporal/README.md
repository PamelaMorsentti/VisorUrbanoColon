# Carpeta temporal

Esta carpeta contiene archivos no necesarios para la ejecucion principal del sistema.

## Estructura

- replit: configuraciones y artefactos heredados de Replit
- diseno_fuentes: planos y documentos fuente de trabajo (DWG, DXF, PDF, CSV, ZIP)
- scripts_auxiliares: scripts puntuales de diagnostico

## Criterio aplicado

Se movieron archivos que no son requeridos para:

- iniciar frontend principal
- iniciar API
- compilar artifacts/colon-3d
- compilar artifacts/api-server

## Restauracion

Si se necesita recuperar algun archivo, moverlo nuevamente a su ruta original en la raiz del repositorio o en scripts/src segun corresponda.
